# RSI：基于实验证据的跨轮改进

[返回首页](../README.md) · [四层架构](ARCHITECTURE.md) · [真实修订案例](../experiments/2026-09-17/rsi_review.md)

RSI 是连接多轮实验的改进层：它接收执行证据，组织诊断和候选修订，经人工审核后，把带适用条件的经验交给下一轮规划。当前实现依赖交互会话与人工复盘；没有自动经验检索、在线训练或未经审核的策略更新。

## RSI 与本轮执行的关系

本轮执行使用冻结后的计划。RSI 在该轮完成或停止后分析证据，不直接修改正在发送的目标流。

```text
本轮：上下文 + 已审核经验 Eₖ → 粗计划 Pₖ → 编译与执行 → 证据 Dₖ
跨轮：Dₖ → 诊断 → 候选修订 Δₖ → 人工审核 → 下一轮经验 Eₖ₊₁
验证：新场景 + Eₖ₊₁ → 重新规划、编译、检查与执行 → 新证据 Dₖ₊₁
```

这里 E 表示人工整理和选用的经验记录，不表示仓库中已经运行的自动记忆服务；Δ 表示计划或配置修订，不表示梯度更新。符号描述工作流，不是自动执行的接口。

## 三份产物把改进过程说清楚

| 产物 | 应记录什么 | 当前承载位置 |
| --- | --- | --- |
| 实验证据 D | 计划标识、命令、反馈、保护原因、任务结果及人工干预 | `experiments/` 中的原始记录、指标、图像 |
| 修订建议 Δ | 观测事实、原因假设、目标层、修改前后、适用范围、验证标准 | 会话中的人工审核；可按复盘模板整理 |
| 经验 E | 被采用的修订、来源证据、适用条件、后续验证结果及限制 | 人工维护的复盘记录，由规划者显式选用 |

[RSI 复盘模板](templates/RSI_REVIEW.md) 是新提供的文档约定，不是原始实验已具备的自动数据管线。[三物体抓取案例](../experiments/2026-09-17/rsi_review.md) 是根据已归档记录做的事后整理，原始日志保持不变。

## 可以修订哪些层

| 目标层 | 可讨论的修订 | 下一轮如何验证 |
| --- | --- | --- |
| L2 任务规划 | 物体顺序、抓取方向、深度、接近/抬升关键点 | 新场景下重新规划，检查抓取与放置结果 |
| L3 轨迹编译 | 动作速度、驻留、轨迹衔接 | 重编译并验证动态限值、几何和事件语义 |
| L4 执行与反馈 | 设备映射、队列或反馈读取问题 | 独立调试与验收后再运行；不通过放宽保护掩盖故障 |

RSI 不应把每次失败都归为“模型不够聪明”。定位偏差、不可达姿态、抓浅、跟踪误差、设备映射错误的证据与处理方式不同。对不确定的原因保留假设状态，不能仅凭一次成功倒推出唯一原因。

## 如何判断改进真的有效

在固定复位协议下比较冻结经验与加入修订的条件，记录重复次数、任务/物体成功率、人工干预、保护停止和总耗时。若同时修改深度与方向，只能把结果归于这组修改；需要进一步对照才能分离各自贡献。

审核经验不是永久许可。场景、物体、桌面、相机、装配或初始状态变化后，必须重新判断适用性。某一轮能够执行与某一轮任务成功，也是两个不同的验证问题。
