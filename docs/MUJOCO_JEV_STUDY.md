# MuJoCo：从感知模式选择到执行时刻的判断

更新：2026-09-23。当前为第一轮物理仿真研究，不能宣称达到顶会水平或复现官方 Jev。

## 已实现

云端安装 MuJoCo 3.6.0、Gymnasium 1.3.0、Gymnasium-Robotics 1.4.1，使用 Fetch v4。
物理步长 2 ms、控制周期 40 ms。GPU 用于小网络训练与 EGL 渲染，标准 MuJoCo 动力学在 CPU 运行。

- Reach：控制链路检查。
- Push、Pick-and-Place：相同固定控制器下的学习型感知模式选择。
- 原始场景模型、接触和动力学使用环境实现；增加的传感器噪声、延迟以及 150 步 horizon 是自定义评测协议，不冒充默认排行榜成绩。
- 控制器资格测试记录“曾成功”“最终成功”“最后十步保持”，不混淆短暂到达和稳定保持。
- 学习实验在连续十步满足环境成功阈值后结束，否则最多 150 步。与资格测试持续运行到终局的口径不同。

## 当前实际 pipeline

1. 环境 reset；已知任务目标，机器人本体状态精确可见。
2. 模拟跟踪器提供带固定横向偏差的物体位置；初始误差幅度已知，实际偏差不可见。
3. 判断器读取任务类型、观测噪声、候选延迟、时间价格、带噪物体与夹爪／目标的相对位置，共 12 维。
4. 约 5k 参数的两层 MLP 输出三个感知模式的成功概率和执行用时估计；没有文字生成或图像编码器。
5. 选择最小 `1 - success_probability + time_price * predicted_duration` 的模式。
6. 保留当前传感器、快速刷新、精确刷新三个候选共用同一控制器。刷新候选先等待，之后跟踪信号仍具有相应的样本年龄。
7. MuJoCo 执行动作，依据实际接触后的目标误差标记结果。

它是 episode 开始时的一次模式选择，不是每步 JEV 决策，也没有把之前解析模拟器的取消等待策略直接接到机器人上。观测噪声由真值合成；因此验证的是状态级部分可观测决策，不是视觉鲁棒性。

## 实验设计

400 个训练场景、120 个验证场景、200 个同分布测试场景、200 个长延迟测试场景；每组平均分给两个任务。
每个场景有三个配对候选，共 2,760 次候选执行。场景 seed 按 split 隔离，三个网络种子 11/22/33，checkpoint 仅由验证集确定。
对照包括全部保留、全部快速、全部精确、验证集最优固定模式、验证集调优的噪声阈值规则。

标签：成功使用 BCE，用时使用归一化 MSE。实际在 CLOUD 开发机 RTX 4090 D 上训练，没有提交 EIP 集群训练任务。
精确执行提交：`efb769c0746d28d3f4bc9d875cafe0ef102d6616`，分支 `research/mujoco-jev-physics`。

## 结果与失败

控制器开发种子 0–9：第一次抓取曾成功 10/10、终局只有 4/10；第二次目标过深导致阶段无法切换，抓取 0/10；第三次修正后抓取终局 10/10。
独立资格场景 seed 1000–1029：Reach 30/30、Pick-and-Place 30/30、Push 23/30 终局成功。Push 控制器仍是明显限制，不能把失败都归因于判断器。

| 分布 / 任务 | 保留当前传感器 | 全部快速刷新 | 全部精确刷新 | 判断器三种子成功率 |
| --- | --- | --- | --- | --- |
| IID / Push | 53% | 65% | 68% | 67%、68%、70% |
| IID / Pick | 68% | 98% | 100% | 98%、99%、99% |
| 长延迟 / Push | 46% | 61% | 68% | 62%、58%、57% |
| 长延迟 / Pick | 69% | 99% | 93% | 99%、99%、99% |

每个格子的分母是 100 个场景；训练种子不是额外独立测试场景。不能拿“优于不刷新”当核心贡献：强固定策略已相当好。
抓取在长延迟下偏好快速模式，推物仍可能偏好精确模式；判断器在推物的分布外泛化退化。结果尚不支持普遍优于规则或固定策略。

第一次录制审计发现成功标签一致，但抓取视频重跑用时与无渲染评测相差 0.08–0.16 s。
已增加完整 MjData 保存／恢复的渲染隔离工具；原始记录保留，修正版单独输出，12/12 通过成功标签和完成时间一致性检查，作为评测配套视频。此检查不等价于所有内部浮点状态逐位相同。

## 下一步有研究价值的问题

**面向动作与阶段的证据有效期。** 同样的样本年龄，在接近物体、闭爪、抬升、推物持续接触中有不同后果。
研究对象应是 `effect(belief, candidate, phase, age, committed_prefix)`，而不是单一 confidence 阈值。
结合固定低层技能，预测“继续当前动作、消费旧观测、等待新观测、取消请求”各自对实际结果的影响。

候选机制（尚未实现）：共享的候选后果预测器 + 阶段相关的观测有效性模型 + 有预算的可取消感知请求。
RSI 先限制为离线反例挖掘：记录判断器与最佳可行候选分歧，增加训练数据并在新留出分布重新验证，避免测试集反复调参。

关键下一轮消融：去掉阶段、去掉样本年龄、去掉已提交动作前缀；与相同技能／观测／预算的规则和已知模型规划器比较。
必须加强 Push 控制器、至少增加一种接触任务，并加入相机感知后才能谈跨任务或视觉层面的结论。

## 与前沿工作的边界

- [TypeSafe Jev](https://typesafe.ai/blog/introducing-system-one-models-and-jev)，2026-09-15 产品发布：结构化非生成判断是借鉴的接口；本实验不是官方模型调用或语言理解能力复现。
- [Real-World Reinforcement Learning of Active Perception Behaviors](https://arxiv.org/abs/2512.01188)，Hu 等，2025-12-01；arXiv 标明 NeurIPS 2025 camera-ready：已有通过训练时特权传感器学习主动感知的工作。因此“机器人学会多看一次”不是独立创新。
- [Real-Time Robot Execution with Masked Action Chunking](https://arxiv.org/abs/2601.20130)，Wang 等，2026-01-27：处理异步执行中的动作与当前感知不一致。我们的候选研究是是否获取／等待／消费信息的决策，不是已实现其动作生成机制。
- [FutureRTC](https://arxiv.org/abs/2607.24008)，Jiang 等，2026-07-27 预印本：预测执行时刻观测来缓解异步错位。必须比较它解决的错位问题，不能把 execution-time conditioning 本身宣称首次提出。
- [The Value of Sensory Information to a Robot](https://proceedings.iclr.cc/paper_files/paper/2025/hash/e1126028d9f1f69c13571ec462084d31-Abstract-Conference.html)，Krishna、Hu、Jayaraman，ICLR 2025：感知价值强烈依赖任务，当前小样本观察与这个问题一致，尚不构成新的理论。
- [Gymnasium-Robotics Fetch](https://robotics.farama.org/envs/fetch/index.html)：任务来源与动作／观测接口。已安装版本注册 v4；网页部分示例仍写 v3，应以本实验版本记录为准。
