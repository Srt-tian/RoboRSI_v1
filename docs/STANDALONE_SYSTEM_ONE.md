# 独立非生成式机器人判断：实验地图

更新：2026-09-23。这里的 System One / JEV 指有限候选、数值输出的研究路线，不是官方模型复现；没有执行时 GPT 调用。具体实现是从模拟标签训练的小型数值网络。

## 已完成的链条

| 实验 | 环境与数据 | 研究对象 | 当前结论 |
| --- | --- | --- | --- |
| 解析第一轮 | 隐物体位置/速度的概率微环境 | 直接后果预测与救回/破坏配对分解 | 配对分解没有稳定超过直接预测，保留负结果 |
| 解析第二轮 | 同一候选的时间效果曲线 | 任务容忍尺度与执行时间条件化 | 长延迟局部小幅收益；高预算已知模型规划器仍更强 |
| 解析第三轮 | 已知队列分布、冻结第二轮模型 | 在请求前选择取消等待期限 | 部分分布优于固定等待，快速运动条件无稳定优势；没有循环停止策略 |
| MuJoCo 第一轮 | Fetch Push / Pick，920 个场景、2,760 分支 | 任务开始时选择传感器模式 | 强固定模式已很强，长延迟推物泛化退化 |
| MuJoCo 第二轮 | 1,500 检查点、4,500 分支、12 模型 | 执行中选择继续/同步刷新/异步刷新 | 长延迟抓取局部收益；同分布阶段查表更强；历史消融无稳定收益 |

前三轮共 42 次实际训练、10,200 个留出场景；第三轮复用模型，不重复计训练量。MuJoCo 实验独立统计，不与解析微环境混为相同任务成绩。

## 当前一次任务的实际流程

任务与目标已给定 → 固定技能执行至检查点 → 带噪旧观测/本体状态/阶段等 29 维输入 → 三个候选分别拼接 one-hot → 6,402 参数 MLP 估计成功与用时 → 最小预计成本候选 → 固定技能在 MuJoCo 执行剩余段 → 独立成功标签和过程归档。

它的决策能力来自模拟分叉执行的监督标签，不来自 GPT 的推理、预训练 VLM、世界模型或人类示范。低层动作生成来自手写技能。已知目标、准确本体状态与可用技能阶段均是明确假设。

## 下一步论文主张需要什么证据

不以“接入 JEV”或“更小网络”作为创新点。优先检验接触阶段下证据的有效性以及反例驱动采样的真实价值。
RSI 必须实际完成训练侧错误发现、定向新增数据、模型更新、新留出测试，并战胜等数据量/等训练量对照。
还需要第三种接触机制、真实图像、完整任务多次判断，以及对先验技能和干净前缀依赖的评估。
现有 Piper 三物体抓取是系统工程背景，不是新判断器的真机验证。
