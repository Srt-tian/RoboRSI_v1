# 延迟证据路由：预注册机制先导

状态：协议冻结前；冻结后填写执行提交与产物索引。2026-09-23。

## 动机与创新边界

已完成的 RSI 等预算实验没有证明反例采样优于随机。新分支检验：相同物理状态、可用观测和控制阶段下，不同已提交动作是否改变最有用的感知流。**把动作队列加入输入本身不是创新**：RTC（Black、Galliker、Levine，2025-06-09，NeurIPS 2025）保留必然执行的动作前缀；ARLI（Zhu 等，2026-08-24，预印本）已经结合已提交动作和推理中途观测做 RL 适配。

研究接口是有限枚举的证据使用方式，而不是生成新动作或修改 VLA 噪声。该差异只是待验证的研究问题，不能据此声称首创或顶会级贡献。时间对齐、滞后观测更新与信息价值也有经典工作，必须加入合理的运输/融合基线。

一手来源：

- [RTC](https://arxiv.org/abs/2506.07339)：现有扩散/流策略上的推理期补全；无需为该接口重新训练。动作前缀不可改。
- [ARLI](https://arxiv.org/abs/2608.23831)：一般策略在推理延迟下的 RL 适配，使用已提交动作和中间观测；不是本项目复现或对比的已运行算法。
- [Belief-dependent macro-action discovery in POMDPs using the value of information](https://sli.csail.mit.edu/spotlight/paper-flaspohler2020neurips/)：低信息价值时选择开环动作，NeurIPS 2020。我们不能把选择何时使用感知作为首创。
- [The Value of Sensory Information to a Robot](https://proceedings.iclr.cc/paper_files/paper/2025/hash/e1126028d9f1f69c13571ec462084d31-Abstract-Conference.html)：ICLR 2025。任务价值而非单纯观测误差是相关既有方向。
- [Localization of Non-Linearly Modeled Autonomous Mobile Robots Using Out-of-Sequence Measurements](https://pmc.ncbi.nlm.nih.gov/articles/PMC3376572/)：延迟/乱序观测的状态估计，2012。末端位移运输不等同于完整 OOSM 滤波器。

## 因果配对与输入边界

- 两个任务 FetchPush-v4、FetchPickAndPlace-v4；复用冻结技能，不修改其行为。干净脚本前缀仅用于构建检查点课程，仍是局限。
- 每个父检查点具有完全相同的 MjData、控制器、历史、快速粗观测、延迟精确观测。
- 三个队列干预：保持 XYZ、以半幅执行当前提议、以原幅执行当前提议。相同持续步数与夹爪命令。每个队列 4/8/12 步，每步 40ms；这是受控恒定命令块，不是训练得到的真实 VLA 动作块。
- 决策时刻在队列之前。路由在队列结束后生效，并固定至剩余回合结束。队列期间所有候选采用相同快速感知来更新控制器阶段，执行完全相同的缓存指令。
- 三种路由：当前粗定位（固定 XY 偏置，σ=1–40mm）、延迟精确定位（固定 1mm 偏置，延迟 2–20 步）、延迟定位加从采样时刻至今的末端位移。后者只是刚性随动假设，在物体仍留在桌上时可能错误。
- 判别器只能看到任务、阶段、观测噪声配置、实际观测年龄、时间价格、目标/两种可用观测相对末端的位置、采样后末端位移、手指编码器、近期末端运动、完整队列。真实物体当前位姿、接触数和仿真结果仅用于标签/审计。
- 无图像、无官方 Jev 权重、无大模型、无动作生成训练；本先导不训练网络。
- 时间成本从分叉开始计，含锁定前缀；总上限 150 步，连续 10 步 Gymnasium 成功。损失为失败指示 + 时间价格 × 秒数。
- 原生 Fetch API 位姿沿用现有实验的缓存语义；Pick 可能比积分态早一个 2ms 物理步。保持采样时刻物体与末端同一 API 时钟，不能把这种误差解释成新机制。

## 可证伪门槛

先导固定 90 个父状态（45/任务），种子 1510000–1510089，270 个队列上下文、810 条路由分支。验证阶段可用测试种子 1510002/1510003，但不用于调参。旧训练、验证、测试集合不复用。

每个父状态的队列盲理想下界差距定义为：先对队列取平均再选最佳路由的损失，减去每个队列分别选最佳路由的平均损失。前者甚至能访问该父状态的全部结果，只要求三个队列共用同一路由；是非常乐观的队列盲理想参考，非可执行基线。

只有同时满足下列条件才进入训练阶段：平均下界差距 ≥0.005；至少 10 个父状态不存在跨三个队列都距最优 ≤0.02 的路由。否则保留负结果并停止本版本，不换种子反复测试至显著。

父状态为独立重采样单位，固定 4000 次配对 bootstrap；不能把队列/路由分支算作独立 N。门槛是开发可行性判断，不是新颖性或显著性证明。

若通过，另行冻结训练协议：父状态级数据划分、队列盲同容量判别器、完整队列判别器、固定路由、任务阶段规则、可部署刚性随动/接触规则；所有选择只用验证集，之后生成新测试。先导不得进入测试统计。

## 完整性与资源

每个队列的三条路线必须逐步精确匹配锁定前缀（动作、qpos、qvel、控制器阶段、可用观测）；检查点跨队列哈希相同；队列之外的模型输入逐值相同。年龄为 0 时，原始与运输后观测应相同，作为运输实现的负对照。
