# 面向双臂 Piper 的非生成判断与 RSI：本轮可证伪方案

状态：2026-09-28 恢复研究。用户重新授权 CLOUD 4090；本轮只进行仿真、离线接口与历史数据验证，没有新的真机运动。
这里的 JEV 指 System One 风格的有限候选判断，不是 JEPA，也不声称复现 TypeSafe 的官方模型。

## 本轮主问题

当闭合或交接命令已经发出，但接触结果尚不明确时，机器人应继续、补看一次、执行一个小幅诊断动作，还是直接重夹？
关键是判断额外证据是否会改变下一步动作，以及获得证据是否值得付出真实时间和接触风险。
单纯“检测失败后重试”“冻结策略加 Q 网络”已有直接相关工作，不作为新贡献。

候选假设：在低自由度双臂操作中，使用**可执行候选之间的结果分歧**来选择诊断动作，并围绕这种分歧采集 RSI 数据，
可能比预测抽象失败类别或不确定性阈值更节省交互。需通过同信息、同候选、同预算的直接 Q 与主动感知基线验证；
若不能稳定胜过这些基线，否决该主张，不以系统集成代替算法贡献。

## 真机约束决定接口

| 环节 | 本轮规定 | 真机对应 |
|---|---|---|
| 感知输入 | 相机帧及时间戳、实测关节、实测夹爪；目标命令独立存储 | 现有相机与 Piper 反馈；不要求新增力矩或触觉传感器 |
| 不可用信息 | 物体真值姿态、摩擦系数、接触力、未来成功标志不得进入判断器 | 仿真真值只用于离线标签和审计 |
| 候选 | 继续、补观测、小幅试提/相对运动、重夹；先经过 IK 和几何检查 | 复用既有有限技能，幅度和轨迹需在对应机械臂上检查 |
| 判断输出 | 候选 ID、预期收益/时间与不确定性；拒绝过期上下文 | 非生成式网络不直接写 CAN，不输出未经编译的任意关节向量 |
| 执行 | 低频判断接入既有平滑与 200 Hz 执行；检查实际发出的命令 | 单写入线程；反馈与命令保持分离 |
| 学习 | 先旁路记录，再离线拟合、冻结比较，最后才考虑现场闭环 | 不边训练边直接改写真机控制参数 |

目前代码证据表明 RoboTwin 的 `get_*_arm_jointState` 读取 drive target，
`get_*_gripper_val` 返回缓存命令。因此 `joint_action/vector` 及其夹爪列不是实测反馈，
不能据此训练“命令闭合即抓取成功”的判断器。实测量必须从 articulation qpos 按关节名提取；
夹爪原始关节坐标和物理开口宽度只有经过对应机构标定后才能互换。

## 拟执行的实验顺序

1. 修复 SAPIEN 退出阶段异常，在相同种子的原生专家任务上核对轨迹、图像和进程退出。
   原来的两次任务完成结果及非零退出码保留；资源清理改善不记作算法提升。
2. 建立只含可部署输入的观测记录，单独检查命令/测量差异、相机时间和迟到观测。
3. 先在抓取/交接的小规模开发场景测试候选是否具有互补性：相同父场景、实际执行分支，
   保留继续、固定重夹、固定诊断等基线。诊断动作与等待都计入相同时间预算。
4. 若最佳固定候选已覆盖绝大多数场景，停止训练选择器；若存在稳定互补，再训练小型视觉+本体状态判断器。
   无诊断直接 Q、总是诊断、夹爪规则、视觉规则与候选机制使用相同可得信息。
5. RSI 的随机、失败优先、不确定性优先、结果分歧优先使用相同新增父场景与执行预算。
   分支按父场景分组，不把相关分支当独立样本，不让同一前缀跨训练/验证/测试。
6. 真机前先用真实 Piper URDF 做离线动作可达性验证，再做只记录的旁路实验。
   仿真任务成功不代表跨构型直接迁移；姿态自由度、夹爪开口和接触材料均需重新验证。

本轮不预先承诺“几百万参数即可达到某成功率”。参数规模、摄像头数和判断频率在数据可辨识性与端到端时延实测后确定。
旧 6,402 参数数值 MLP 的结果不能作为新视觉模型的性能或真机证据。

## 本轮补充核查的最近邻工作

- **RoboRecover**，Yang Li 等，2026-09-24 预印本：[正文](https://arxiv.org/html/2609.28952v1)。
  已覆盖从执行中间偏差恢复、跨策略纠正示范及监测触发修复。
  其恢复协议重新给定恢复步数预算；我们的拟议完整回合实验需另报诊断/等待/重夹总预算，不能混算成功率。
- **FAR: Failure-Aware Retry for Test-Time Recovery and Continual Policy Improvement**，Haoran Hao 等，
  2026-07-01 预印本：[正文](https://arxiv.org/html/2607.01111v1)。
  已结合失败对比偏好适配、重试扰动和后续策略改进，并报告真实机械臂实验。
  因此“失败负样本 + 平滑扰动 + RSI”这一组合本身不能作为本项目创新。
- **Q-Planning**，Varun Giridhar 等，2026-08-21 预印本：[官方项目](https://q-planning.github.io/)。
  冻结 BC、候选动作块评分以及只更新 Q 的成功/失败回放已有结果；必须作为直接方法对照。

这些差异目前是实验设计与待验证假设，不构成排他性原创声明。后续还需核查主动感知、双重控制、
接触状态估计与执行约束下的价值学习，避免换术语重复已有问题。

## 本轮固定的接口与候选预检

- 原生抬锅、交接各一次均完成且子进程返回 0。交接新旧 3,778 步的控制目标与实测 qpos 完全一致；
  抬锅相差 5 步，不能宣称全部任务轨迹等价，也不能凭两个案例宣称环境全面稳定。
- 新观测从 articulation 按 URDF 关节名提取 qpos/qvel，实测夹爪坐标与 drive target 分开。
  交接 3,778 行逐一核对；夹爪差值可能同时包含接触、跟踪滞后和其它误差，不直接作成功标签。
- Piper 预检固定抽取历史三物体任务的 24 个等距反馈帧，每帧 5 个动作：上移 20 mm、X/Y 各正负 15 mm。
  保持夹爪和另一臂不变，使用现有有界 IK、几何检查、速度/加速度约束和平滑，逐点检查 200 Hz 输出。
  这 120 个相关候选不是独立抓取试验；历史地面参数与中心线几何不能替代现场标定或完整场景碰撞检查。
- RoboTwin 开发预检固定 seed=0，在交接场景中只执行“首次抓取—试提—保持”的自定义子任务，
  不报完整交接成功率。初始规划 X 偏差为 -40/0/+40 mm；固定候选为继续、开夹后 X -20/+20 mm 重夹。
  共 3 个父条件 × 3 个候选，统一上限 2,500 物理步，开夹、修正、试提及 0.4 秒保持均计入。
  初始提案仍使用特权原生专家；候选修正只用测得的末端位姿与固定相对偏移。
  以相同前缀命令/实测状态摘要及分叉物体姿态核查配对，不将独立 reset 宣称为精确 simulator snapshot。
  如果同一固定候选覆盖所有成功情况，或配对不成立，则不启动选择器训练。

时间戳接口区分采集与可用时刻，拒绝时钟混用和迟到图像。当前仿真渲染时物理暂停，不能用这些时间戳
冒充真实异步相机结果。真机接口只离线适配已有标准化 q14；本轮未打开 CAN。

## 首轮预检与配对修正

120 个历史 Piper 候选中，105 个通过，5 个因有界 IK 不可达被拒绝，10 个因起始 TCP 超出本轮
保守空间边界被拒绝。沿用同一预设边界，没有为了通过率放宽。FK 与历史记录的最大位置差为
约 1.2e-16 m。这只是记录/模型的一致性，不证明实际标定误差为零。

首次 9 个开发分支均正常退出：无偏差的 3 个分支成功，±40 mm 条件下的 6 个分支均失败。
每个固定候选均覆盖 1/3 条件，事后最优候选也只覆盖 1/3，未观察到训练选择器的收益空间。
同时，独立规划的前缀步数发生变化（负偏差组为 1003/1004/1001），因此不能宣称同状态反事实比较。

追加的是**配对实现验证**，不以提高成功率为目标：从每组预先排第一的“继续”分支中提取两段初始规划，
固定 position 和 velocity，重新执行负 40 mm 条件的 3 个候选。选择该组是因为其前缀不一致已被测出；
不按成功与否挑选前缀。必须核对完整前缀命令/实测摘要与分叉物体姿态，再报告匹配是否成立。
保持上限 2500 步和候选动作不变。结果出来前不启动视觉选择器训练，不把配对修复计为算法收益。

追加验证已完成：三条分支均退出 0，前缀都为 1003 步，完整摘要与原来第一条分支一致，
分叉物体姿态差为 0。三条仍失败。配对实现门槛通过，但当前固定重夹候选没有展示救回能力；
本轮没有新训练模型。下一步优先测试更早的观测时机，以及在候选普遍无效时更新局部目标。
