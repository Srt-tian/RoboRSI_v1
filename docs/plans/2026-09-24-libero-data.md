# LIBERO 演示数据接入与研究边界

## 已确认的数据

已有 LeRobot v3 数据包含 Panda 的 40 个语言任务、1,693 条演示、273,465 帧。
每帧含 8 维状态和 7 维动作；两路 256×256 AV1 视频，标注频率 10 Hz。
40 个任务各有 29–50 条演示，不能称为统一 50 演示/任务的完整发布。
私有存储地址和运行主机路径仅保存在本机脱敏运行台账，不写入公开仓库。

`scripts/libero_dataset_audit.py` 对现有数据只读处理：计算所有文件的 SHA-256，
检查动作与状态有限性、全局索引、逐回合帧号与时间戳、任务一致性、Parquet 指针，
逐个核对视频的时长和帧数。三个示例预先固定为任务 ID 0、2、8 的首条演示；
两路画面按回合时间段解码，逐帧保存原始动作供页内同步查看。
视频头检查不等价于逐帧解码全部 74 个视频。数据集只声明 train，未提供独立算法测试划分。

```bash
python scripts/libero_dataset_audit.py \
  --dataset /path/to/libero-v3 \
  --output /path/to/new-audit-output \
  --preview-tasks 0 2 8
```

## 这些数据能支持什么

用于实现数据读取与视觉/动作对齐、训练成功演示上的基础策略或表征。
不能单靠这些成功演示证明恢复能力、因果诊断或 RSI 采集优势。
视频中的完成任务是演示本身的行为，不是新方法的闭环结果。

## 后续检验顺序

1. 对照转换源代码与实际仿真，确认两路相机、状态布局、旋转表示、夹爪符号和动作缩放。
   维度与数值范围相似不构成兼容性证明。
2. 固定任务、训练演示子集与仿真初始状态；先建立可执行的基础策略，报告逐任务闭环成功率。
3. 在物理仿真中构造可比较的观测失真与接触失败，测量继续、观察、动作修复的实际后果。
   只使用部署时可得输入；额外观察、等待和探测动作均计入任务时间与交互预算。
4. 与直接 Q 排序、固定规则、滤波和主动观测基线对比，使用相同策略、容量、信息与训练量。
5. RSI 分别采用随机、失败驱动、不确定性和候选因果反例采集；保持相同父场景/分支预算，
   按父场景分组切分，验证集冻结后再评测独立测试集。

创新性仍是待证假设。Q-Planning、RAYA、Dream2Fix、EgoRecovery、
LIBERO-RECOVER 与 REVERSAL-BENCH 的已覆盖问题见前沿性记录；不把
“冻结策略 + 小判断器 + 失败自改进”本身作为新贡献。
