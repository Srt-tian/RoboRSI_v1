# Standard FetchSlide: SAC + HER development baseline

Status: preregistered bounded development pilot, not a new-method result.

The frozen fixed skill achieves only 6/100 final-step successes on registered
FetchSlide-v4. This is insufficient to judge a sensor-routing algorithm. Retain
that negative result and train a separate conventional lower-level baseline.

- Task: original sparse-reward FetchSlide-v4, normal reset, default 50 steps.
- Implementation: Stable Baselines3 2.8.0 SAC with future HER (4 relabelled goals).
- Environment: Gymnasium 1.2.3, Robotics 1.4.1, MuJoCo 3.6.0, Torch 2.7.1.
  This separate compatible environment differs from the existing Gymnasium 1.3.0
  fixed-skill environment. Verify environment behavior before comparing results.
- Actor and twin critics: 256-by-256 ReLU MLPs; batch 256; learning rate .001;
  gamma .95; tau .05; automatic entropy; buffer 250,000 transitions; no input
  normalization; 10,000 initial exploration transitions; seed 11.
- Four vectorized environments; one gradient update per vector step (four
  transitions). Initial budget 250,000 transitions, one seed. This is a pilot,
  not a claim of adequate sample complexity or seed robustness.
- Full privileged observation dictionary to four normalized continuous actions.
  No vision, no judgment network, no GPT, no sensor robustness claim.
- Evaluate deterministic policy at initialization and every 25,000 transitions
  on the same 50 validation seeds 2,810,000--2,810,049. Rank checkpoints by final
  step `is_success`, then final distance. Do not select on episode return alone.
- Keep every validation curve/seed metric, best/final models, and replay buffer.
  No held-out test until this development run and the method are frozen.
- A 400-transition / 2-validation-episode smoke run can exercise replay updates
  with learning starting at 100, then is discarded from effectiveness statistics.

Primary implementation documentation:
https://stable-baselines3.readthedocs.io/en/master/modules/her.html

This is a baseline training configuration chosen for this study, not a claim to
reproduce published FetchSlide performance. The published RL Zoo FetchReach
configuration is not a validated FetchSlide configuration.
