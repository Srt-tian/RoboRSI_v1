1. 原版 Fetch-v4 完整 reset、默认 50 步；校准 320 回合，独立技能留出
   400 回合。Reach / Push / PickAndPlace / Slide 最后一步成功率分别为
   100% / 88% / 91% / 6%。这不是学习判断模块的成绩。

   强滤波基线必须保留；低状态误差不总对应高任务成功率，但小样本排序不能
   当作待提方法有效的证据。没有在这一数据上训练新判断模型。
3. 上一轮 RSI 的失败案例采样没有稳定胜过随机采样；队列可见性的预注册
   训练门槛没有通过。以上负结果约束下一轮设计，不应只挑有利指标。

## 候选主问题：观测误差与接触失误的干预可辨识性

拟检验：当两段可见历史都表现为“没有进展”，到底应补充观测还是改变接触？
将所有情况都当作低动作价值，可能无法区分：

- 感知偏差：执行器行为正常，但目标位置估计错误；补观测可能有效。
- 接触失效：位置估计合理，但抓取滑脱、插入受阻或双臂交接失败；单纯补观测
  可能耗尽恢复窗口，需要改变接触方式。

候选模块使用真实可得的图像/状态历史、时间戳和执行反馈，输出对有限干预的
**相对任务效果及不确定性**。干预包括继续、补观测、局部接触修正；仅在现有
信息无法区分且有实际任务价值时，执行一个有界诊断动作。RSI 更新数据优先
采自“相同可见失败征兆、干预效果相反”的案例，并与随机采样等预算比较。

这仍可能被主动感知、双重控制、POMDP 或既有恢复研究覆盖。目前不命名为
新算法，不声称首次，也不认为增加几个输出头就足够。只有新的监督机制或
决策机制被实现、与直接 Q 模型公平比较后仍有独立效果，才考虑保留主贡献。

## 最先执行的可证伪检查

1. **可执行性**：先确认冻结执行策略能在原版困难任务完成任务；仿真能启动、
   零动作能跑、专家能运行都分别记录，不算新算法有效。
2. **干预必要性**：在开发场景的完整物理快照上比较固定候选；若最强固定策略
   已近似覆盖所有场景，停止训练选择器。完整快照只用于离线标签。
3. **可辨识性**：去除模拟器真值和未来帧后再训练；若只能靠不可部署输入获得
   收益，将结果标作特权信息上限，不作为真机可行性证据。
4. **机制消融**：相同编码器、参数量、候选和数据，比较直接 Q 评分、阶段规则、
   不确定性阈值、候选机制；分别去掉诊断动作、历史、时间戳、结构化监督。
5. **RSI 消融**：相同新增父场景数、分支数、训练更新量，比较随机、失败优先、
   不确定性优先和候选采样机制。保留改善失败场景但破坏正常任务的情况。
6. **真实预算**：共同计算感知、策略采样、诊断动作、恢复和物理执行耗时；
   等候或主动观测消耗任务时间。禁止为新方法单独延长时限。
7. **独立验证**：开发、验证、测试按任务/初始场景分组；同一场景的分支不跨
   数据集，不作独立样本。方案冻结后再开启测试，至少报告三训练种子和
   按父场景配对的不确定性区间。具体样本量在 pilot 后用功效分析确定。

## 困难任务分层

- **LIBERO-Long (`libero_10`)**：先固定全部任务与官方初始状态清单，选择
  包含抽屉、容器和多对象操作的开发任务；最终避免只报挑选任务。
- **RoboTwin 2.0**：接入双臂交接、协作搬运或精细接触任务，先使用官方
  执行/采集入口验证。保留原版与随机化配置的独立统计。
- **LIBERO-RECOVER**：在代码和场景资产版本可核验后补恢复起点测试；
  这是独立扩展，不能与标准 LIBERO reset 成功率合并。
- **Fetch**：保留轻量机制诊断和回归测试，但不作为顶会主实验的充分证据。

所有过程量、动作、图像时间戳、失败类别、候选评分、训练曲线和固定案例
视频写入同一实验格式；本机 Web 展示摘要和可审计小缓存，大文件留在远端。

## 部署与复现

- 大体积数据、模型与资产只在指定数据主机下载，先检查磁盘、代理、来源
  大小和小试传。已有 RoboTwin 环境可做依赖参考，未经 Git 来源核验的快照
  不直接用于新实验。不同模拟器使用独立环境。
- 已有 Piper IK/轨迹平滑/200 Hz 执行可以复用为后端。Fetch 策略不直接
  移植到 Piper；判断模块先进行只记录的旁路比较，再验证局部受限修正。
- 尚无新真机运行；历史入筐成功不构成新 JEV/RSI 方法的实验证据。
