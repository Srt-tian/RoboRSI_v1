# 先导失败后的时间对齐诊断

这是看到 90 个父场景先导结果后增加的控制实验，不是独立测试，不改变原先导的失败判定。先导提交 b731cb8799ec0918e1a7b56074cb44421de45f11。

冻结规则：`精确旧观测 + 当前粗观测 - 同采样时刻的粗观测`。同一回合的粗传感器偏置不变，因此差分能消除粗偏置；在现有观测模型下，结果代数上等于当前物体位置加精确传感器的 1mm 偏置，误差仅来自浮点运算。该规则保留了一个历史粗观测样本；今后若训练判别器，所有比较方法也必须可以访问这一历史样本。

对先导的全部 90 个父场景和 3 个队列增加一条路线，共 270 条新分支。先前 810 条分支保持字节不变。检查新分支的整段锁定前缀与归档精确一致。差值按父状态先聚合三个队列，然后做 4000 次 bootstrap；只作开发诊断。

回放固定先导编号 0、1、4、5，选择原幅提议队列的四种路线，共 16 段视频。回放归档积分状态，不重新运行物理；按 Fetch 原生观测缓存时间校验 FK。结论无论正负都发布，不挑选最佳视频。

如果简单时间对齐已经足够，下一步应更换不合理的传感器假设，并加入固定延迟平滑器等基线，而不是把该特例包装成学习算法的贡献。
