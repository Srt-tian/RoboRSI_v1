# 研究方案：意图约束的稀疏轨迹修订与跨轮校准

**主张：让 GPT 一次给出“可修订的完整计划”，让后续模块判断何时、在哪里、在多大范围内需要改变；RSI 学习这些修订的适用条件。** 模型选型是变量，不把方案绑定在 Jev、某个 VLM 或特定异步推理算法上。

这是一版待验证研究方案。v0.3 实现了其离线契约、判断、拒判、追溯与评测基础，尚未实现本文所有在线功能。已有三物体真机成功属于固定计划版本，不能作为新方案的性能证据。

另外已完成一个[运动学决策沙盒](SIMULATION.md)：576 个 episode、全量过程和六段对照视频验证了版本复查的作用。它采用规则提案器，不是本方案的学习模型或真机性能实验；结果也显示必须保留即时规则基线。

## 1. 为什么选择这个问题

已有实验表明，在那个经过准备的桌面场景中，GPT 给出整段粗计划、确定性模块生成 200 Hz 目标流，可以连续完成三个物体的抓取。剩余关键问题不是每隔几十毫秒重新生成所有动作，而是物体位置、接触状态或阶段结果与计划预期不一致时怎么办。

修订有两种成本：调用和等待，以及对已经良好的轨迹造成干扰。我们关注**保留有效计划，只为有证据的偏差付出修订成本**。这也避免小模型既负责看图、估计位置，又自由生成整条轨迹，难以定位错误来源。

## 2. 提议的核心表示：计划带着预期和修订范围

研究目标中的一次 GPT 输出为：

$$
\mathcal P = \{W_k,\; C_k,\; \mathcal R_k,\; B_k\}_{k=1}^{K}.
$$

| 项 | 含义 | 当前状态 |
| --- | --- | --- |
| $W_k$ | 第 k 阶段粗关键点、夹爪事件、物体/目标标识 | 粗关节关键点与事件已有；语义物体绑定仍需扩展 |
| $C_k$ | 阶段预期：哪些可观测量应在什么范围，缺少什么量不能下结论 | 已有离线数值区间契约；尚无自动视觉事实提取或时序逻辑验证 |
| $\mathcal R_k$ | 局部修订族，例如调整接近方向、抓取深度、局部时间配置 | 已有同拓扑关节候选比较与 1×/2× 枚举；TCP 参数化修订待实现 |
| $B_k$ | 修订预算、观测预算和升级条件 | 已有关节改动范围、请求年龄/概率门限；在线预算优化待实现 |

Piper 自由度有限时，修订族可以允许姿态误差与位置误差按任务权重折中；这些容许值由任务与几何检查确定，不由判断模型擅自放宽。桌面 TCP 高度只是约束之一，不能覆盖肘部、手爪侧面、物体与双臂碰撞。

**具体例子：**“夹爪闭合开度偏小”只能说明与预期接触不符，不能直接推出“应该再向下 8 mm”。先判断目标仍在原位置、是否空夹或侧向偏移；证据足够才比较带条件的修订候选。重复空夹与已有物体滑落也应对应不同恢复阶段。

## 3. 三种职责和两个时间尺度

**计划与修订生成。** GPT 在开始时生成完整计划；仅在候选族不足、任务关系改变时再次调用。候选生成器也可由模板、优化器或局部策略实现。约束“通常只调用一次”应作为待测调用预算，不能预设所有扰动都无需第二次推理。

**事件判断。** 观测模块输出带来源、时间和不确定性的事实。阶段检查器先区分正常、缺观测、超出预期和违反硬限制。只有值得比较候选时，才向 Jev/本地判断器提交有限菜单。模型只选择 `review_candidate / collect_evidence / ask_planner / abstain`，代码组合独立问题的结果。未来在线动作选择需要单独的受控接口，本版只有离线审核建议。

**连续执行。** IK、重编译、几何/动态检查和平滑决定动作能否落地；单写者按固定 200 Hz 下发。判断器不运行在这个线程，模型 token 速度也不决定控制频率。

未来若在线替换轨迹，应冻结已经提交的动作前缀，以新鲜实测状态重建未执行段，检查连接处位置/速度连续、夹爪事件恰好一次及阶段锁。过时回复不得覆盖新计划。这些在线替换机制仍需实现和真机验收；当前 `contracts.py` / `judgment.py` 只验证快照路由、版本与时效。

## 4. 原创性应落在哪里

### A. 修订的有效域，而非笼统的失败反思

把一条经验表示为“什么任务意图、什么阶段、哪些观测条件下，哪一种局部变化有效”。同时记录没有帮助或导致退化的修订。RSI 需要学习的是适用域与候选覆盖率，而不是不断追加“再夹深一点”的文本。

可检验假设：相同大模型调用预算和相同候选库下，带适用条件的修订选择，比泛化文本记忆更少误修订。与 Zetta 等框架的区别必须在这组受控实验中成立，不能仅依赖模块命名。

### B. 将“该看更多”与“该动不同”联合比较

在判断状态不充分时，重新观测也应成为有成本的候选。研究目标可以写成：

$$
a^* = \arg\min_{a\in\{\mathrm{continue,observe,repair,replan}\}}
\widehat L(a\mid s,\mathcal P) + \lambda_t T(a) + \lambda_c C(a),
$$

其中 $\widehat L$ 需要真实标签或配对实验估计，绝不能直接把模型自报概率当损失。当前实现只有显式路由和门限，没有训练这个代价模型或实现信息增益优化。

### C. 让异步建议具备有效期和可检验身份

判断绑定 `(program hash, contract hash, phase, semantic revision, scope)`。请求前与返回后都检查当前状态；同一阶段内发生物体移位也应提升语义 revision，而不是只靠阶段名。当前已实现这个离线门控协议。

后续在线 observer 应只在与决策相关的事实变化时提高 revision，并有防抖与去重，否则每个传感帧都使建议过期。漏掉真实变化同样危险；revision 的正确性是待验证感知假设，hash 本身不提供真实性或安全证明。

## 5. RSI 如何形成真正可测的改进

1. 在决策时冻结输入快照、候选全集、验证结果、模型版本和分布，不能把终局结果回填进决策输入。
2. 结果来自独立观测或人工标注，分别记录动作完成、抓取保持、物体入筐和保护停止；候选未执行时，其物理效果仍为未知。
3. 对同一失败分布做可复位的配对试验，比较修订与不修订。真机不能回滚到完全相同世界，因此报告复位偏差；不要把历史后一次成功称为反事实因果证明。
4. 先更新经验范围、候选检索和拒判阈值；样本足够后再蒸馏本地判断器。评测时冻结记忆、阈值和模型。
5. 按 episode / 场景 / 物体划分开发与留出集，评估在新摆放上的提升，而不是在参与修订的样本上报告“自我进化”。

已实现的 `calibrate` 只在 validation 选择阈值，再在不重叠 group 的 test 上报告 Brier、NLL、ECE、覆盖率与接受后错误率。它没有拟合概率校准器，也不是 conformal 风险保证；按物体/场景隔离和标签质量仍需数据构建者负责。

## 6. 论文实验矩阵

| 条件 | 改变什么 | 回答什么 |
| --- | --- | --- |
| 固定粗计划 + 连续执行 | 无在线任务修订 | 保留当前强基线，不能只和差的逐点控制比较 |
| 相同契约 + 规则选择 | 相同观测、候选、验证器和时限 | 学习型判断是否胜过工程规则 |
| 每次异常 GPT 重规划 | 相同异常/观测触发条件 | 稀疏修订能否节省时间与调用且保持成功率 |
| 结构化判断，无跨轮更新 | 冻结通用判断器 | 单靠 System One 是否有收益 |
| 结构化判断 + 范围化 RSI | 只更新经验/阈值或小模型之一 | 改进到底来自哪一部分 |

必做消融：去掉拒判、去掉语义版本复查、去掉补观测选项、打乱状态/任务指令、固定候选但更换判断器、固定判断器但扩展候选库、独立改深度/方向。这样可以区分真正理解状态、利用先验捷径、以及候选库本身更好的情况。

**任务建议：**沿用胡萝卜/青椒/茄子入筐，增加摆放变化、局部遮挡、受控位移和易滑接触。先采小规模 pilot 估计方差，再确定所需 episode 数，不预设几十次就足以支持论文。每种方法应使用配对复位协议并随机化顺序，公布所有分母、失败与人工干预。

**指标：**任务/物体成功、恢复成功、错误修订率、无必要干预率、候选覆盖率、拒判覆盖—风险曲线、模型调用与费用、总墙钟/P95、保护停止、连续性和主机发令周期。分开报告 provider、重编译、等待和执行耗时，网页整理在轮次结束后进行。

**失败判据：**如果规则基线在相同候选与预算下已经同样好，就保留规则；如果主要瓶颈是目标定位而不是候选选择，应优先改感知。Jev 或任何小模型都不是必选组件。

## 7. 当前交付与下一步顺序

| 已实现并可离线运行 | 尚待实现 / 验证 |
| --- | --- |
| 数值阶段契约、缺观测/偏差/硬限制分型 | 视觉/接触事实提取、在线事件去重与防抖 |
| 同基线受约束候选、完整概率分布校验、拒判 | TCP 参数化修订族、动态候选覆盖评测 |
| 请求指纹、时限、推理前后语义版本复查 | 在线轨迹前缀冻结、剩余段替换与原子提交 |
| 禁用/合成/replay provider、可选 TypeSafe HTTP 接口 | 真实服务验证、本地开放模型部署与机器人域标注 |
| 判断关联审核/经验、本机 Web、分组留出评分 | 自动训练、因果收益估计、真实连续恢复 |

建议先完成 **TCP 参数候选 + 感知事件记录**，在影子模式下比较规则/判断器；只在候选质量和接受后错误率有证据之后，接入低速单物体恢复，再扩大到连续多物体。整套研究围绕“有效域可学习的局部修订”推进，而不是围绕增加模型数量推进。
