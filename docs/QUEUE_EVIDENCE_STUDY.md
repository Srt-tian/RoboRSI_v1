## 研究问题与最接近工作

相同当前状态与观测下，不同尚未执行的动作能否改变使用哪种感知流的最佳决策？

- **RTC**：Kevin Black、Manuel Y. Galliker、Sergey Levine，*Real-Time Execution of Action Chunking Flow Policies*，2025-06-09 首次提交，NeurIPS 2025。保留保证会执行的动作并补全后续动作，基于现有扩散/流策略，无需为此重新训练。它已经处理不可改动作前缀。[论文](https://arxiv.org/abs/2506.07339)
- **ARLI**：Brian Zhu 等，*Learning to Act While Waiting: RL Finetuning of Generalist Robot Policies Under Inference Latency*，2026-08-24 首次提交，8 月 26 日 v2，预印本。通过 RL 适配既有一般机器人策略，状态中包含已提交动作和推理中间观测；报告仿真和真实操作实验。我们没有运行其完整算法，不能作性能优越性对比。[论文](https://arxiv.org/abs/2608.23831)
- **信息价值与动作块**：Genevieve Flaspohler、Nicholas Roy、John W. Fisher III，*Belief-dependent macro-action discovery in POMDPs using the value of information*，NeurIPS 2020。从 POMDP 模型和信念值函数构造动作块，在信息价值较低时开环执行；不是视觉感知误差上的学习路由器。[作者页](https://sli.csail.mit.edu/spotlight/paper-flaspohler2020neurips/)
- **乱序观测估计**：Eva Besada-Portas、Jose A. Lopez-Orozco、Pablo Lanillos、Jesus M. de la Cruz，*Localization of Non-Linearly Modeled Autonomous Mobile Robots Using Out-of-Sequence Measurements*，Sensors，2012-02-23。梳理并比较非线性机器人定位中的延迟/乱序滤波，含模拟与真实导航验证；本项目的差分控制不是该论文完整滤波算法的复现。[全文](https://pmc.ncbi.nlm.nih.gov/articles/PMC3376572/)

有限枚举的非生成判断接口仍是工程设计方向，但“信息价值”“队列条件化”“时间对齐”都不能直接宣称首创。

## 冻结的先导

两个 Fetch 任务各 45 个父状态。每个父状态分成保持、半幅提议、原幅提议三个锁定队列，队列长 4/8/12 步；三个队列共用观测与物理检查点。每个队列比较当前粗观测、延迟精确观测、按末端位移校正精确观测三种路线，共 **810 条分支**。

路由在锁定队列之前选定，队列结束后生效，直到回合结束保持不变。锁定期间各路线的动作、观测和物理状态必须逐步完全一致。控制周期 40ms、物理步长 2ms，剩余上限 150 步；连续 10 步环境成功才计为成功。成本为失败指示加时间价格乘秒数。

在任何结果出现前，设定训练门槛：队列盲理想下界与队列可见理想选择器的平均成本差至少 0.005，并至少有 10 个父状态出现明显最佳路线变化（没有一个跨队列通用路线始终距最优不超过 0.02）。这只是开发可行性门槛。

| 指标 | 结果 |
| --- | --- |
| 独立父状态 / 队列上下文 | 90 / 270 |
| 队列信息理想平均收益 | 0.002986 |
| 父状态 bootstrap 描述性区间 | [0.000480, 0.007480] |
| 明显最佳路线变化 | 5 / 90 |
| 预设门槛 | **未通过** |
| 本轮新模型训练 | **0** |

理想收益按定义非负，不能仅凭区间下界大于零解释成确认性显著性证据。该理想参考能访问每个父状态的真实执行结果，不能部署为策略。

## 事后时间对齐控制

看完先导结果后加入一个无需训练的控制：

`校正位置 = 精确旧观测 + 当前粗观测 − 同时间戳的历史粗观测`

现有传感器用回合内不变的加性偏置；差分会抵消粗偏置。该规则得到当前物体位置加精确传感器残余偏置，且不需要知道偏置值或接触关系。它使用一个保留的历史粗观测样本；今后所有比较方法都应获得相同历史访问能力。

在相同 90 个父状态、270 个队列上增加 **270 条新分支**，原先导记录不改动。

| 路线 | 分支成功率 | 平均成本 ↓ |
| --- | --- | --- |
| 当前粗观测 | 76.67% | 0.50066 |
| 延迟精确观测 | 95.56% | 0.29134 |
| 末端位移校正 | 62.96% | 0.68623 |
| 传感器差分校正，事后控制 | **99.63%（269/270）** | **0.20068** |

后者相对延迟精确观测的成本差为 −0.09066，父状态聚合后 bootstrap 区间 [−0.14395, −0.04651]。其中 Push 为 134/135，Pick 为 135/135。270 个队列分支来自 90 个父状态，不能当作 270 个独立样本。

这是开发场景的事后诊断，不能解释成新学习方法的性能，也没有证明优于前一轮 phase/RSI 的判断器——两轮感知流定义不同。它说明本轮的固定偏置假设可以被简单估计器大幅利用；合理的时间对齐基线必须先于复杂学习模块。

## 下一步的验收条件

1. 更真实的观测过程：独立帧噪声、漂移、遮挡和重新关联错误；按父场景生成可重放噪声，候选共用相同外生随机量。
2. 先建立强估计基线：时间戳对齐、差分运输、固定延迟平滑或偏置状态滤波；所有方法访问相同传感器历史。
3. 在正确估计器仍不足的任务后果上寻找判断价值，例如不可撤销的接触/释放错误；先检验可避免损失，再决定是否增加学习复杂度。
4. 通过机制门槛后再冻结训练、模型容量对照、独立种子测试；增加第三类接触任务与完整回合多次判断。

截至本轮，创新性仍未得到充分支持。保留强基线推翻假设的结果，是继续筛选方向的依据。
